# Versioned Python Agent SDK

The Python agent SDK will be released as package `consoler-agent-sdk` from the consoler Git repository, starting at SDK version `0.1.0`, while continuing to declare protocol compatibility separately from the package version. The first release coordinate is the Git tag `consoler-agent-sdk-v0.1.0`, installed with a pip VCS URL or PEP 508 direct reference to `#subdirectory=sdks/python`. Build, metadata, and installed-package smoke checks belong in the normal validation path; no internal package-index upload or package-index credentials are part of the release flow.
