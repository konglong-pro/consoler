Historical consoler phase gates, closeouts, and validation evidence live here.

Current groups:

- `consoler-v1/`: V1 release and closeout evidence.
- `consoler-v2/`: artifact retrieval/browser release and closeout evidence.
- `consoler-v3/`: Intent Drafting and assisted intent gate evidence.
- `consoler-v4/`: indbase variant dogfood, intent drafting, friction, and NL v2 evidence.

Do not read archived testing evidence by default. Resolve current gates through `docs/testing.md`, `docs/phase-manifest.yaml`, and `docs/active/current.md`.
