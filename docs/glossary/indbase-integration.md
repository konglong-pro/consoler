# Indbase Integration Glossary

## Terms

**indbase Console Variant Probe**: Narrow indbase-adapted Console Variant used to dogfood trusted workflows through consoler's existing lifecycle.

**indbase Dogfood UX Variant**: Consoler-owned refinement of indbase product labels, ordering, navigation, empty states, and artifact flows without changing indbase business logic.

**Source Trust Loop Action Surface**: Ten-command indbase variant action set: doctor, ingest file, search sources, document show, review list/show, task list/show, and error list/show.

**Single-Source Trust Walkthrough**: Dogfood path through one vault and one source: health check, ingest/prepared state, governed search, artifact inspection, review/task/error inspection, history, and trace.

**Indbase Variant Intent Drafting**: Deterministic Source Trust Loop form-prefill accelerator inside the indbase variant.

**Indbase NL v2 Intent Drafting**: Opt-in assisted drafting after deterministic drafting is insufficient, still producing one editable Source Trust Loop form.

**Governed Filters**: Host-product filters such as tags or categories. Consoler must not infer them from vague semantics unless an active phase defines explicit syntax and validation.

**Artifact Open/Back Path**: Minimal UX where a user opens an accepted artifact block, inspects the bounded agent-owned view, and returns to action timeline or trace.
